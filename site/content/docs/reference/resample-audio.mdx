---
title: "resampleAudio"
description: "Resample PCM audio between sample rates."
---

Converts linear PCM from one sample rate to another, which realtime sessions
need when a microphone's rate does not match what the provider expects.

```swift
let resampled = resampleAudio(samples, from: 48_000, to: 24_000)
```
