---
title: "detectAudioMediaType"
description: "Identify an audio format from its bytes."
---

Sniffs the container from the leading bytes and returns a media type. Used
internally by [`transcribe`](/docs/reference/transcribe) when the declared
type is generic; exposed because it is useful on its own.

```swift
let mediaType = detectAudioMediaType(data)  // "audio/mp4", "audio/wav", ...
```
