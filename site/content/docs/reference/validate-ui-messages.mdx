---
title: "validateUIMessages"
description: "Validate incoming UI messages, throwing on bad input."
---

Checks that messages from a client are well formed before you hand them to a
model. Throws on the first problem.

For a non-throwing check, use
[`safeValidateUIMessages`](/docs/reference/safe-validate-ui-messages).

```swift
let messages = try validateUIMessages(body.messages)
```
