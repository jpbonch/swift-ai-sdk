---
title: "fingerprintTools"
description: "Snapshot tool definitions so changes can be detected."
---

Hashes each tool's name, description, and schema into a fingerprint you can
store. Pair it with
[`detectToolDrift`](/docs/reference/detect-tool-drift) to notice when a
remote server changes a tool after a user approved it.

```swift
let approved = fingerprintTools(try await mcp.tools())
```
