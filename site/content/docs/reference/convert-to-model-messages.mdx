---
title: "convertToModelMessages"
description: "Convert UI messages to model messages."
---

Maps the `UIMessage` shape a client sends into the `Message` values a model
takes, flattening UI-only parts. This is the first thing a server route does
with an incoming chat body.

```swift
let messages = convertToModelMessages(body.messages)
```
