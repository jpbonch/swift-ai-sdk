---
title: "cosineSimilarity"
description: "Cosine similarity between two vectors."
---

Pure arithmetic, no network call. Returns a value from -1 to 1, where 1 means
the vectors point the same way.

Vectors of different lengths, or a zero vector, return 0 rather than throwing.

```swift
let score = cosineSimilarity(queryVector, documentVector)
```
