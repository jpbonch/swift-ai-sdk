---
title: "wrapProvider"
description: "Wrap every model a provider produces."
---

Applies middleware at the provider level, so every model the provider hands
out is already wrapped. Saves repeating the same wrapping at each call site.

```swift
let provider = wrapProvider(
  provider: myProvider,
  languageModelMiddleware: [.cache()]
)
```
