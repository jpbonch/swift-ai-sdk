---
title: "getRealtimeToolDefinitions"
description: "Convert tools into realtime session definitions."
---

Maps ordinary SDK tools into the shape a realtime voice session expects, so
one tool array can serve both a text loop and a voice session.

```swift
let definitions = getRealtimeToolDefinitions(tools)
```
