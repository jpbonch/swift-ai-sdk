---
title: "wrapEmbeddingModel"
description: "Wrap an embedding model with middleware."
---

The embedding-model counterpart to
[`wrapLanguageModel`](/docs/reference/wrap-language-model), using
`EmbeddingModelMiddleware`.

```swift
let embeddings = wrapEmbeddingModel(
  model: OpenAIEmbeddingModel("text-embedding-3-small"),
  middleware: [.defaultSettings(maxBatchSize: 96)]
)
```
